# ZENITH404 – AI-Based Legal Assistant

## About the Project

ZENITH404 is an AI-Based Legal Assistant designed to make legal information more accessible and simplify common legal tasks. The platform helps users obtain preliminary legal information, explore relevant case laws, analyse legal documents and generate legal templates through a single web application.

The system combines AI-assisted processing with document management and legal information retrieval to provide users with a convenient and interactive legal assistance platform.

## Key Features

### 1. Legal Question Answering
- Allows users to ask legal questions in natural language.
- Provides AI-assisted responses based on the available legal knowledge base.
- Maintains conversation history.

### 2. Case Law Search
- Enables users to search for relevant legal cases.
- Supports searching using keywords, jurisdiction and case citations.
- Displays matching case references and summaries.

### 3. Legal Document Analysis
- Supports PDF, DOCX and TXT document uploads.
- Extracts text from uploaded documents.
- Uses AI-assisted analysis to generate summaries and identify important clauses.

### 4. Legal Template Generation
- Provides predefined legal document templates.
- Allows users to fill in dynamic fields.
- Generates downloadable legal documents in DOCX format.

### 5. Feedback Management
- Allows users to submit ratings, comments and error reports.
- Enables administrators to review and manage feedback.

### 6. User and Admin Management
- Provides authentication and role-based access control.
- Allows administrators to manage users, legal references and templates.
- Maintains separation of user-specific data.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React, Vite, JavaScript |
| Backend | Python, FastAPI |
| Database ORM | SQLAlchemy |
| Database | SQLite |
| AI Integration | LLM-based processing |
| Document Processing | PyPDF, python-docx |

## System Architecture

The application follows a frontend-backend architecture:

1. The React frontend provides the user interface and collects user requests.
2. The FastAPI backend handles API requests and application logic.
3. SQLAlchemy manages communication with the database.
4. AI/LLM integration supports legal question answering and document analysis.
5. The backend returns processed results to the frontend for display.

## Project Objective

The primary objective is to develop an accessible, AI-assisted platform that brings legal information retrieval, case-law search, document analysis and legal document generation together in one application.

**Note:** The platform provides preliminary legal information and assistance. It is not a substitute for professional legal advice.
